# 运营 / 市场岗位速查（日报 · 看板 · 数据清洗 · 排版）

> 面向运营、新媒体、市场、增长岗的高频操作。每条给「作用 / 公式(或操作) / 示例 / 注意」。
> 通用函数（VLOOKUP / COUNTIFS / SUMIFS / IF / LEFT / MID / TEXT 等）基础语法见《excel-formulas》篇，本篇讲运营场景怎么用。
> 分类：增长指标计算 → 日报周报做表 → 文本清洗与拆平台 → 去重与核对 → 表格美化排版

## 增长指标计算

### 环比增长率
- **作用**：本月比上月涨了多少
- **公式**：`=(本月-上月)/上月`
- **示例**：`=(B2-A2)/A2`，单元格格式设成"百分比，保留 1 位小数"
- **注意**：上月为 0 会爆 #DIV/0!，外面包 `=IFERROR((B2-A2)/A2,"-")`；负数代表下滑，条件格式标红

### 同比增长率
- **公式**：`=(本月-去年同月)/去年同月`
- **示例**：`=(B2-B14)/B14`（假设去年同月在第 14 行）
- **注意**：同比要避开大促月（618、双 11 当月同比没意义），汇报时加一句"去年同期含大促"

### 占比计算
- **公式**：`=该项/总和`
- **示例**：某渠道 GMV 占比 `=C2/SUM($C$2:$C$10)`，格式设百分比
- **注意**：分母要加 $ 锁死，往下拉才不会变；最后一行加个 100% 校验行

### 完成率 / 目标达成率
- **公式**：`=实际完成/目标`
- **示例**：`=B2/C2`，配条件格式 <80% 红、80–100% 黄、>100% 绿
- **注意**：目标数为 0 同样要 IFERROR 一下

### 日均 / 月均
- **公式**：`=总金额/天数`
- **注意**：天数别直接写 30，用 `=DAY(EOMONTH(今天,0))` 自动取当月天数；跨月数据用 `=DATEDIF(开始,结束,"D")+1`

### 客单价
- **公式**：`=GMV/订单数`
- **注意**：退款订单要不要算进去，口径先和数据对清楚，别周报里一个口径月报里另一个

### 留存 / 复购（思路）
- **思路**：某日新增用户中，过了 N 天还回来的比例。复杂公式在 Excel 里写起来费劲，推荐：用数据透视表"行放注册日期、列放回访日期、值放去重用户数"，交叉看留存矩阵
- **注意**：真要写公式用 COUNTIFS 多条件数"注册日 + 回访日"交集；别硬写 SUMPRODUCT 数组

## 日报周报做表

### 数据透视 5 秒出日报
- **操作**：后台导出原始明细 →「插入」→「数据透视表」→ 行放"渠道"，值放"UV、下单数、GMV"三个字段
- **注意**：源表加了新行要记得刷新；每天的数据导出来追加到同一个 Sheet，别每天新建表

### 按渠道 / 按活动拆分
- **操作**：透视表里把"活动 ID"拖到列区，行留"日期"，一眼看每个活动每天的贡献
- **注意**：活动命名要规范（"618 预热"和"618预热"是两列），先 TRIM 和 SUBSTITUTE 清空格

### 同比 / 环比列直接在透视里算
- **操作**：点值字段 →「值显示方式」→「差异百分比」→ 基本字段选"日期"，基本项选"上一个"
- **注意**：比自己写公式省事，而且源表刷新后自动重算

### 周报模板固定布局
- **思路**：建一个 Sheet 叫"周报"，标题、本周数据、上周对比、下周计划四块写死，数据区全部引用"明细"Sheet 的透视表结果；每周只要刷新透视，周报自动更新
- **注意**：别在周报 Sheet 里手填数字，下次就不知道改哪了

### 条件格式做数据条
- **操作**：选中一列数字 →「开始」→「条件格式」→「数据条」→ 选个颜色
- **场景**：渠道 GMV 一列，长短条一眼看谁大谁小，不用人工比大小
- **注意**：数据条不影响实际数值，打印也好看

## 文本清洗与拆平台

### TRIM 清导出数据里的空格
- **公式**：`=TRIM(A2)`
- **场景**：从抖音 / 抖店 / 后台导出来的昵称常带前后空格，VLOOKUP 对不上就是这个原因
- **注意**：TRIM 只处理半角空格；中文全角空格（　）要配合 `=SUBSTITUTE(A2,"　","")` 再清一遍

### LEFT / RIGHT / MID 拆 URL 或渠道码
- **公式**：`=LEFT(文本, N)` 取前 N 个；`=MID(文本, 起, 长度)` 中间取
- **示例**：链接 `https://xhs.cn/p/abc123?from=douyin`，想取平台名：`=MID(A2, FIND("from=",A2)+5, 10)`；取到截断为止用 LEFT 配 FIND
- **注意**：URL 参数位置不固定时，用 FIND 定位比写死第几位稳；找不到 FIND 会报错，外面包 IFERROR

### SUBSTITUTE 统一命名
- **公式**：`=SUBSTITUTE(A2, "小红书", "XHS")`
- **示例**：把"小红书""紅薯""红书"统一替换成"XHS"，方便透视分组
- **注意**：替换是精确匹配，大小写、空格不一样就替换不到，先 TRIM

### 拼接文案 / 链接
- **公式**：`=A2 & " - " & B2`
- **示例**：把"标题"和"链接"拼成一行贴进群公告；数字要先 ROUND 或 TEXT，否则拼出来一串小数

### 去掉多余换行 / 不可见字符
- **公式**：`=CLEAN(TRIM(A2))`
- **场景**：从网页复制过来的文本带一堆换行和零宽字符
- **注意**：CLEAN 清的是不可打印字符，全角空格它不管

## 去重与核对

### 删除重复值后计数（操作法）
- **操作**：选中关键列（比如用户 ID）→「数据」→「删除重复值」→ 看底部弹框"发现 X 个重复值，保留 Y 个唯一值"，Y 就是去重后人数
- **注意**：会直接改原表，先复制一份再删；想看"哪些是重复的"别直接删，加一列 `=COUNTIF(A:A,A2)`，大于 1 的就是重复

### SUMPRODUCT 去重计数（老版本兼容写法）
- **公式**：`=SUMPRODUCT(1/COUNTIF(A2:A100, A2:A100))`
- **注意**：区域里不能有空单元格，否则会除零；新版 Excel / WPS 直接用"删除重复值"操作更稳，这个公式只在必须保留原数据时用

### 两张导出表并排 VLOOKUP 核对
- **作用**：今天的后台数据和昨天导出来的对不上，逐列看哪里变了
- **操作**：两张表按同一排序放一起，或在一张表里 VLOOKUP 另一张的 GMV，旁边写 `=本表值-对照表值`，差额不为 0 的标红
- **注意**：先把两表按"日期+渠道+活动"拼一个键列（`=A2&B2&C2`），再按键 VLOOKUP，比单条件准

### 导出表格式不统一
- **思路**：从不同平台导出来的列名、日期格式都不一样，最稳妥是建一张"标准表"，每张导出表都用 VLOOKUP / 复制粘贴对齐到标准列，再做透视
- **注意**：别每张表直接透视，最后拼不回来

## 表格美化排版

### 统一字体与字号
- **操作**：整表选中 → 字体设成微软雅黑 / 思源黑体，标题 12 号加粗，正文 10 号；数字列右对齐、文本列左对齐
- **注意**：汇报用的表不要用超过 2 种字体；数字一定要右对齐，看大小才顺

### 边框只加横线，不加竖线
- **操作**：选中数据区 →「开始」→ 边框 → 只加"上框线、下框线、表头下框线"，竖线全去掉
- **注意**：白底 + 细横线比全是格子线干净十倍，给老板看的表一律这么做

### 条件格式色阶做热力图
- **操作**：选中数值列 →「条件格式」→「色阶」→ 绿黄红三色
- **场景**：一周每天的 GMV 矩阵，颜色深浅直接看出哪天是高峰
- **注意**：色阶和数据条二选一，别同时加，画面太乱

### 关键指标放大显示
- **操作**：周报第一行放 3–5 个核心数（DAU、GMV、转化率），字号调到 16–18 号加粗，旁边小字写环比
- **注意**：老板打开表第一眼要看到这几个数，别让他在几十行里找

### 冻结首行首列
- **操作**：「视图」→「冻结窗格」→「冻结拆分窗格」（选在数据区左上角格子的右下一格）
- **场景**：横看渠道纵看日期，滚来滚去都能看到行列名

### 打印 / 截图适配
- **操作**：「页面布局」→ 方向选横向 → 缩放选"将所有列调整为一页"
- **注意**：发给同事前先打印预览一下，别让列被切到第二页

## 链接与渠道标记

### UTM / 渠道参数拼接
- **公式**：`="https://xxx.com?" & "utm_source=" & A2 & "&utm_medium=" & B2`
- **注意**：参数值里不要有中文和空格，有空格用 SUBSTITUTE 替成 `%20` 或短横线

### 短链 / 活码数量盘点
- **思路**：一张表登记每个投放链接用的短链、渠道、开始结束时间，每周拉一次点击数据 VLOOKUP 进来
- **注意**：短链过期时间单独列一列，条件格式"距离过期 <7 天"标黄

## 数据导出常见坑

### CSV 打开乱码
- **操作**：直接双击 CSV 经常中文乱码；正确做法是「数据」→「从文本/CSV」导入，文件 origin 选"65001: Unicode (UTF-8)"
- **注意**：WPS 同样在"数据 → 导入数据"里选 UTF-8

### 后台导出日期是文本
- **操作**：选中该列 →「数据」→「分列」→ 下一步 → 列数据格式选"日期 YMD" → 完成
- **注意**：比写 --TEXT 转要稳，尤其一整列格式混乱时

### 导出数字带逗号千分位
- **公式**：`=SUBSTITUTE(A2,",","")*1`
- **注意**：直接乘 1 会把文本数字转成数值；不想转就只 SUBSTITUTE

## AB 实验与活动

### AB 实验分组统计
- **思路**：数据透视表行放"实验组别"，值放核心指标均值；用 IFERROR 包好，别因为某组样本为 0 报错
- **注意**：实验刚开始样本少时别看显著性，等样本量够再下结论

### 活动期间数据标色
- **操作**：选中日期列 →「条件格式」→「新建规则」→ 用公式判断是否落在活动区间，比如 `=AND(A2>=活动开始, A2<=活动结束)` → 设浅黄底
- **注意**：活动开始结束日期放两个固定单元格引用，改活动不用改规则

### 竞品数据周对比表
- **思路**：自建一张表列"本周自 / 本周竞品 / 差值"，竞品数据手动填（或从公开周报抄），差值列写条件格式
- **注意**：竞品数据来源要在表底注明，别自己编
