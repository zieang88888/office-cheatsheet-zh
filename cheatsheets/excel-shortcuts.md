# Excel / WPS 快捷键速查（高频 · 职场版）

> 只收录每天都会用到的快捷键与快捷操作。每条给「作用 / 操作 / 示例 / 注意」，默认对 Microsoft Excel 生效，WPS 表格多数一致，差异处单独注明。
> 分类：编辑录入 → 选择与移动 → 视图与显示 → 数据与格式 → 公式计算 → 工作表管理 → WPS 差异

## 编辑录入

### F2 直接编辑当前单元格
- **作用**：不用双击，进入单元格编辑状态，光标停在文字末尾
- **操作**：选中单元格按 `F2`
- **示例**：改一长串备注时，选中按 F2 直接改，不用再找光标位置
- **注意**：如果按 F2 变成在单元格右下角显示内容，说明关了"单元格内直接编辑"，到「文件→选项→高级」打开"允许直接在单元格内编辑"即可

### Alt+Enter 在同一个单元格里换行
- **作用**：一个单元格里写多行文字（地址、多行备注）
- **操作**：双击进入编辑状态，光标点到要换行的位置按 `Alt+Enter`
- **示例**：把地址写成"北京市 / 海淀区 / 中关村大街 1 号"三行
- **注意**：直接按 Enter 是跳到下一格，不会在格内换行

### Ctrl+Enter 把选区批量填成同一个内容
- **作用**：选中一片区域，输入一次内容，所有选中格都填上同样的东西
- **操作**：先框选区域 → 直接打字 → 打完按 `Ctrl+Enter`（不是普通 Enter）
- **示例**：把空白负责人列批量填成"待分配"
- **注意**：配合 `Ctrl+G` 定位空值使用，是最快的批量补漏手段

### Ctrl+D 向下填充
- **作用**：把上面一格的内容或公式复制到下面选中的区域
- **操作**：选中"上面那格 + 下面要填的格"，按 `Ctrl+D`
- **示例**：A2 是公式，选中 A2:A20 按 Ctrl+D，全部套上同样公式
- **注意**：`Ctrl+R` 是向右填充，方向别搞反

### Ctrl+'（单引号）复制上一行的公式
- **作用**：把正上方单元格的公式原样抄下来，不做引用调整
- **操作**：选中目标格按 `Ctrl+'`（英文单引号，Tab 上方那排键）
- **示例**：每行公式结构一样时，快速复用上一行
- **注意**：和 `Ctrl+Shift+"`（复制上一行显示的值）别混；老版本行为一致

### Delete 只清内容不删格子
- **作用**：清空选中格的文字，但保留单元格本身和格式
- **操作**：选中按 `Delete`
- **注意**：右键"删除"会把整个格子删掉、旁边的格顶上来；Delete 只是清空内容

### F4 重复上一步操作
- **作用**：不在编辑公式时，按 F4 等于"再来一遍刚才那个动作"
- **操作**：做完一个操作（比如插一行、设黄色填充），选中其他位置按 `F4`
- **示例**：给 A1 涂了黄色，选中 B1 按 F4 立刻也涂黄
- **注意**：**正在编辑公式时 F4 是切绝对/相对引用**（A1↔$A$1 循环），两个功能不冲突，区别就在你当时是不是在公式栏里打字

### Ctrl+Z / Ctrl+Y 撤销 / 重做
- **作用**：误操作往回退一步；退多了再前进
- **注意**：保存关闭后再打开，历史记录就清空了

## 选择与移动

### Ctrl+方向键 一秒跳到数据边缘
- **作用**：在连续数据区域里，直接跳到这一摞数据的最上/最下/最左/最右
- **操作**：按住 `Ctrl` 再按 ↓↑←→
- **示例**：表格有 5000 行，光标在 A2 按 `Ctrl+↓` 直接跳到最后一行
- **注意**：中间遇到空格会停在空格前一格；想一口气跳到底就先把空行补上

### Ctrl+Shift+方向键 连续选中一整段
- **作用**：从当前格一直选到数据边缘，不用拿手拖
- **操作**：按住 `Ctrl+Shift` 再按方向键
- **示例**：选中 A2 后按 `Ctrl+Shift+↓`，整列数据一次选完
- **注意**：配合 `Ctrl+Shift+L` 一键套筛选，或者直接复制一整列

### Shift+方向键 逐格扩展选区
- **作用**：一次选一格、一格一格往边上扩
- **操作**：按住 `Shift` 再按方向键
- **注意**：配合鼠标点"另一头的格子"再按 Shift，能选一大段矩形

### Ctrl+Home 一键回到 A1
- **作用**：表格滚到几千行外，一秒回到左上角
- **操作**：`Ctrl+Home`
- **注意**：`Ctrl+End` 反过来，跳到"最后一个有内容的单元格"

### Shift+空格 选中整行 / Ctrl+Shift+空格 选中整列
- **作用**：整行整列选中，比点行号列号快
- **操作**：光标放行里按 `Shift+空格` 选整行；按 `Ctrl+Shift+空格` 选整列
- **注意**：笔记本上 Ctrl+空格常被输入法占用，用 `Ctrl+Shift+空格` 即可；再按一次能选中整张表

### Ctrl+G（F5）定位条件
- **作用**：按条件批量选中，比肉眼找快
- **操作**：`Ctrl+G` →「定位条件」→ 选空值/常量/公式/对象等
- **示例**：定位空值后直接输入内容按 Ctrl+Enter，批量补空

### Alt+PageDown / Alt+PageUp 左右翻屏
- **作用**：一页一页向右/向左翻列
- **操作**：`Alt+PageDown` 向右翻一屏，`Alt+PageUp` 向左
- **注意**：单独按 PageDown/PageUp 是上下翻行

## 视图与显示

### Ctrl+`（反引号）切换公式显示
- **作用**：把单元格里"显示的结果"切成"看到底写的什么公式"，对账时特别好用
- **操作**：按 `Ctrl+``（数字 1 左边那个键，和波浪号 ~ 同键）
- **示例**：怀疑有人把公式粘成了死值，切一下立刻看出来
- **注意**：再按一次切回正常显示；这是全局开关，整张表都切

### Ctrl+鼠标滚轮 缩放显示比例
- **作用**：字太小看不清、或要缩小看全局，直接滚轮拉
- **操作**：按住 `Ctrl` 滚鼠标滚轮
- **注意**：这只是视图缩放，不改变实际字号和列宽

### Ctrl+PageDown / PageUp 切换工作表
- **作用**：在 Sheet1、Sheet2、Sheet3 之间来回切
- **操作**：`Ctrl+PageDown` 切到右边下一张表，`Ctrl+PageUp` 切回左边上一张
- **注意**：右键点左下角那个左右箭头，可以弹出所有工作表列表直接选

### 冻结窗格 表头永远不动
- **操作**：选中表头下面那一行的第一个格子 →「视图」→「冻结窗格」→「冻结拆分窗格」；只想冻一行就选「冻结首行」
- **场景**：几千行的表往下滚时，表头一直钉在顶上

### 新建窗口并排对比两张表
- **操作**：「视图」→「新建窗口」→「全部重排」→ 选"垂直并排"
- **场景**：两个部门的表左右对着看，不用来回切

## 数据与格式

### Ctrl+Shift+L 一键开关筛选
- **作用**：给表头加上/去掉筛选下拉箭头
- **操作**：光标放在数据区任意位置按 `Ctrl+Shift+L`
- **示例**：筛"销售部"、筛"金额大于 1000"
- **注意**：再按一次取消筛选；这是用得最多的数据操作之一

### Alt+= 一键求和
- **作用**：自动在选中区域下方或右边填好 SUM 公式
- **操作**：选中要合计的那一列（**多往下框一格空的**），按 `Alt+=`
- **示例**：B2:B10 是数据，选中 B2:B11 按 Alt+=，B11 自动出现 `=SUM(B2:B10)`
- **注意**：横着求和就往右边多框一格；选错范围它会瞎猜，按完检查一下公式

### Ctrl+T 一秒套上超级表
- **作用**：把普通一片数据变成"智能表格"——自动套色、自动扩展、自带筛选
- **操作**：光标在数据区按 `Ctrl+T`，确认对话框里"表包含标题"打勾
- **示例**：以后在下面新填一行，公式和格式自动带过去
- **注意**：WPS 里叫"智能表格"，入口和快捷键一样；套完想转回去：「设计」选项卡 →「转换为区域」

### Ctrl+E 快速拆分/合并/清洗文本
- **作用**：你手动给它写一两个例子，它猜你想干嘛，自动把整列做了
- **操作**：在旁边一列写好第一个想要的结果，选中下面一格按 `Ctrl+E`
- **示例**：A 列是"张三（销售部）"，B1 手动写"张三"，光标放 B2 按 Ctrl+E，整列名字拆出来
- **注意**：Excel 2013 及以后才有；WPS 表格新版本已支持，老版本没有；它是"猜"的，做完逐行抽查

### Ctrl+; 插入今天日期（写死的）
- **作用**：在单元格里填入当天日期，固定不变
- **操作**：选中格按 `Ctrl+;`（分号）
- **示例**：登记单据时盖个"今天"的章
- **注意**：`=TODAY()` 是活的、每天自动变；`Ctrl+;` 是死的、就是敲下去那一刻的日期

### Ctrl+Shift+: 插入当前时间
- **作用**：填入现在几点几分
- **操作**：按 `Ctrl+Shift+:`（冒号，分号那个键加 Shift）
- **注意**：只精确到分钟；日期+时间想同时写就按完 `Ctrl+;` 打个空格再按 `Ctrl+Shift+:`

### Ctrl+1 打开单元格格式面板
- **作用**：所有数字格式、对齐、边框、填充都在这一个面板里
- **操作**：选中格按 `Ctrl+1`
- **注意**：比右键"设置单元格格式"快；想改边框、对齐就从这里进

### Ctrl+Shift+3 日期格式
- **作用**：把一串日期数字一键变成标准日期显示
- **操作**：选中格按 `Ctrl+Shift+3`
- **示例**：把 2026/10/1 显示成带年月日的样式
- **注意**：显示成什么样跟你系统区域设置有关；要自定义格式就进 Ctrl+1

### Ctrl+Shift+4 货币格式
- **作用**：数字前面自动加货币符号，千分位隔开
- **操作**：选中金额列按 `Ctrl+Shift+4`
- **示例**：1234567 显示成 ¥1,234,567.00
- **注意**：只是显示格式变了，单元格里还是数字，能继续算

### Ctrl+Shift+% 百分比格式
- **操作**：选中格按 `Ctrl+Shift+%`
- **示例**：0.85 显示成 85%

### Ctrl+Shift+! 两位小数
- **操作**：选中格按 `Ctrl+Shift+!`
- **注意**：只改显示位数，不真的四舍五入；想真正四舍五入用 ROUND 函数

### Ctrl+Shift+~ 回到"常规"格式
- **作用**：各种被搞乱的格式一键还原成默认
- **操作**：选中格按 `Ctrl+Shift+~`（波浪号，和反引号同键加 Shift）

### Ctrl+5 删除线
- **操作**：选中文字按 `Ctrl+5`
- **场景**：标记"已作废"的内容

### Alt+↓ 调出本列历史输入
- **作用**：同一列里以前打过的词，直接下拉选，不用重新打
- **操作**：光标放单元格里按 `Alt+↓`
- **示例**：之前在这列输过"销售部"，新行里按 Alt+↓ 直接选
- **注意**：和数据验证做的下拉不一样，这个是自动从本列历史里抓的

## 公式计算

### F9 / Shift+F9 手动重算
- **作用**：有时候公式显示旧值不刷新，手动逼它算一遍
- **操作**：`Shift+F9` 只重算当前表；`F9` 重算整个工作簿
- **注意**：正在编辑公式时按 F9 会把选中的那一段真的算成数值，按 Esc 退出才不会污染公式

### 名称框快速跳到指定区域
- **作用**：左上角那个显示"A1"的小框，直接输地址回车就跳过去
- **操作**：点名称框，输入 `B500` 回车，瞬间跳到 B500
- **示例**：输入 `C:C` 回车直接选中整列 C

## 工作表管理

### Shift+F11 一秒插入新工作表
- **作用**：在当前表前面加一张空白 Sheet
- **操作**：按 `Shift+F11`
- **注意**：鼠标点底部那个"+"号也行；WPS 同样支持

### 工作表标签右键菜单
- **操作**：在底部 Sheet1 标签上右键
- **能干的事**：插入、删除、重命名、移动或复制（勾选"建立副本"就是复制一张）、标签颜色、隐藏
- **注意**：双击标签直接重命名，最快

### Ctrl+拖拽标签 = 复制一张工作表
- **操作**：按住 `Ctrl` 鼠标拖着 Sheet 标签左右移，松开就复制出一张副本
- **场景**：要做"1 月、2 月"结构一样的表，复制模板改

### 隐藏 / 取消隐藏工作表
- **操作**：右键标签 →「隐藏」；要恢复：任意标签右键 →「取消隐藏」选那张
- **场景**：放参数表、数据源，不想让别人乱动

## WPS 与 Excel 的差异（避免 confusion）

### Ctrl+E 快速填充的支持情况
- **说明**：Excel 2013 起原生支持；WPS 表格近年版本已跟进，菜单在「数据」选项卡
- **注意**：如果按 Ctrl+E 没反应，去「数据」选项卡找"快速填充"按钮，或者升级 WPS；别以为是自己按错了

### Ctrl+T 超级表 vs 智能表格
- **说明**：WPS 里叫"智能表格"，入口在「插入」选项卡，效果类似但个别功能（如表样式、计算列）比 Excel 略简
- **注意**：互相打开时一般不会坏，但复杂表样式在 WPS 里可能掉格式

### 快捷键整体一致
- **说明**：本文件列的绝大多数快捷键，WPS 表格都能直接用；少数涉及 F4、Alt 组合键的行为也基本一致
- **建议**：公司电脑 Excel/WPS 混用时，记住核心那 15 个，其他用到再查本文件
