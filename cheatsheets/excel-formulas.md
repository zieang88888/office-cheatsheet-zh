# Excel 公式速查（高频 · 职场版）

> 只收录日常工作中真正用得上的公式与操作。每条给「作用 / 公式 / 示例 / 注意」，照着抄就能用。
> 分类：查找引用 → 条件统计 → 逻辑判断 → 文本处理 → 日期时间 → 数学统计 → 表格操作技巧

## 查找引用

### VLOOKUP 精确查找（最常用的查找函数）
- **作用**：按一个关键字，在表格某一列里查找，返回同一行其他列的值（如：用工号查姓名）
- **公式**：`=VLOOKUP(查找值, 表格区域, 要返回第几列, 0)`
- **示例**：`=VLOOKUP(A2, 员工表!$A$2:$D$500, 4, 0)` —— 在员工表的 A 列找 A2 的工号，返回该行第 4 列
- **注意**：最后的 `0` 表示精确匹配，**一定不要省**；查找值必须在区域的第一列；区域加 `$` 绝对引用，往下拉公式才不会跑偏

### INDEX + MATCH 组合查找（比 VLOOKUP 更灵活）
- **作用**：想从右边往左边查、或列数经常变动时用，VLOOKUP 做不到的它能做
- **公式**：`=INDEX(返回区域, MATCH(查找值, 查找列, 0))`
- **示例**：`=INDEX($C$2:$C$500, MATCH(A2, $B$2:$B$500, 0))` —— 在 B 列找 A2，返回 C 列同一行的值
- **注意**：`MATCH(..., 0)` 的 0 也是精确匹配；返回区域和查找列可以任意左右，不受"查找值必须在第一列"限制

### XLOOKUP（Excel 2021 / WPS 新版通用）
- **作用**：新一代查找函数，VLOOKUP 和 INDEX+MATCH 的活它都能干，还支持找不到时给提示
- **公式**：`=XLOOKUP(查找值, 查找列, 返回列, [找不到时显示什么])`
- **示例**：`=XLOOKUP(A2, 员工表!B:B, 员工表!D:D, "查无此人")`
- **注意**：老版本 Excel（2016 及更早）没有此函数，团队版本不统一时慎用

## 条件统计

### SUMIFS 多条件求和
- **作用**：满足一个或多个条件才求和（如：某部门某月份的销售额合计）
- **公式**：`=SUMIFS(求和区域, 条件区域1, 条件1, 条件区域2, 条件2, ...)`
- **示例**：`=SUMIFS(销售表!E:E, 销售表!A:A, "销售部", 销售表!B:B, "2026-01")`
- **注意**：条件加引号；文本条件可用 `"销售部"`，数字直接写 `2026`；条件支持通配符 `*`（如 `"张*"` 匹配所有张姓）

### SUMIF 单条件求和
- **作用**：一个条件求和
- **公式**：`=SUMIF(条件区域, 条件, 求和区域)`
- **示例**：`=SUMIF(A:A, "北京", C:C)`

### COUNTIFS 多条件计数
- **作用**：统计满足条件的单元格个数（如：统计某状态的单据数量）
- **公式**：`=COUNTIFS(条件区域1, 条件1, ...)`
- **示例**：`=COUNTIFS(B:B, "已完成", C:C, ">=1000")`

### AVERAGEIFS 多条件求平均
- **公式**：`=AVERAGEIFS(平均区域, 条件区域1, 条件1, ...)`
- **示例**：`=AVERAGEIFS(D:D, A:A, "运营部")`

## 逻辑判断

### IF 条件判断
- **作用**：满足条件返回一个值，不满足返回另一个
- **公式**：`=IF(条件, 满足时返回, 不满足时返回)`
- **示例**：`=IF(C2>=60, "及格", "不及格")`

### IFERROR 屏蔽错误值
- **作用**：公式算错（#N/A、#DIV/0! 等）时，显示你指定的文字，而不是刺眼的报错
- **公式**：`=IFERROR(原公式, 出错时显示什么)`
- **示例**：`=IFERROR(VLOOKUP(A2, 员工表!A:D, 4, 0), "未找到")`

### IF 嵌套多条件（不超过 3 层为宜）
- **公式**：`=IF(条件1, 结果1, IF(条件2, 结果2, 结果3))`
- **示例**：`=IF(A1>=90, "优", IF(A1>=80, "良", "一般"))`
- **注意**：超过 3 层建议改用 IFS 函数（新版支持 `=IFS(条件1,结果1,条件2,结果2,...)`）或用辅助列

## 文本处理

### LEFT / RIGHT 截取文本
- **公式**：`=LEFT(文本, 截取几个字)` / `=RIGHT(文本, 截取几个字)`
- **示例**：`=LEFT(A2, 2)` 取身份证前 2 位（省份码）；`=RIGHT(A2, 4)` 取后 4 位
- **注意**：一个汉字按 1 个字计算，不需要乘 2

### MID 截取中间文本
- **公式**：`=MID(文本, 从第几个字开始, 取几个字)`
- **示例**：`=MID(A2, 7, 8)` 从身份证第 7 位开始取 8 位 = 出生日期（如 19900101）

### TEXT 数字转显示格式
- **作用**：把数字按指定格式显示（日期、金额、补零等）
- **公式**：`=TEXT(数字, "格式代码")`
- **示例**：`=TEXT(A2, "0000")` 把 5 显示成 0005；`=TEXT(A2, "yyyy-mm-dd")` 把日期显示成 2026-01-05
- **注意**：TEXT 的结果是文本，不能再参与加减乘除

### 文本连接：& 或 CONCATENATE
- **公式**：`=A2 & B2` 或 `=CONCATENATE(A2, B2)`
- **示例**：`=A2 & "（" & B2 & "）"` 输出"张三（销售部）"
- **注意**：数字会直接拼进去，不想要小数位就先 ROUND 或 TEXT

### SUBSTITUTE 替换指定文字
- **公式**：`=SUBSTITUTE(文本, 要找的文字, 换成什么, [换第几个])`
- **示例**：`=SUBSTITUTE(A2, " ", "")` 去掉所有空格；`=SUBSTITUTE(A2, "-", "/", 1)` 只替换第一个"-"
- **注意**：替换全部时不写第 4 参数；只替换第 N 个时写第 4 参数

### TRIM 清理多余空格
- **公式**：`=TRIM(文本)`
- **作用**：去掉文字前后和中间多余的空格（从系统导出的数据常有这种问题）

## 日期时间

### TODAY 今天日期
- **公式**：`=TODAY()`
- **注意**：每次打开文件都会更新；要固定当天日期用快捷键 `Ctrl+;`

### DATEDIF 计算间隔（工龄、账龄神器）
- **公式**：`=DATEDIF(开始日期, 结束日期, "单位")`
- **单位**：`"Y"` 整年、`"M"` 整月、`"D"` 整天、`"YM"` 忽略年份的月数、`"YD"` 忽略年份的天数
- **示例**：`=DATEDIF(A2, TODAY(), "Y")` 算入职日期到今天的整年数（工龄）

### EDATE / EOMONTH 日期加减月
- **公式**：`=EDATE(日期, 加几个月)` / `=EOMONTH(日期, 加几个月)`
- **示例**：`=EDATE(A2, 6)` 六个月后的同一天；`=EOMONTH(A2, 0)` 本月最后一天
- **场景**：算合同到期日、算账期、算月末结账日

### WEEKDAY 判断星期几
- **公式**：`=WEEKDAY(日期, 2)`
- **示例**：返回 1=周一，7=周日；配合 IF 可做"周几标签"

### 年月日拆开：YEAR / MONTH / DAY
- **公式**：`=YEAR(A2)` / `=MONTH(A2)` / `=DAY(A2)`
- **场景**：数据透视表的月份分组、按年对账

## 数学统计

### ROUND 四舍五入
- **公式**：`=ROUND(数字, 保留几位)`
- **示例**：`=ROUND(A1*0.13, 2)` 保留两位小数（算税常用）；负数表示到十位/百位（`=ROUND(1234, -2)` → 1200）

### RANK 排名
- **公式**：`=RANK(数字, 排名区域, [0降序/1升序])`
- **示例**：`=RANK(B2, $B$2:$B$50, 0)` 从大到小排名
- **注意**：排名区域要绝对引用；新版可用 `RANK.EQ`

### SUMPRODUCT 多条件计数/求和的万能写法
- **作用**：不想写数组公式时，一个函数搞定复杂条件
- **计数**：`=SUMPRODUCT((A:A="销售部")*(B:B="2026-01"))`
- **求和**：`=SUMPRODUCT((A:A="销售部")*(B:B="2026-01")*C:C)`
- **注意**：条件用括号包起来；老版本整列引用(A:A)可能卡，建议用具体区域 $A$2:$A$500

### MOD 取余（判断奇偶、隔行处理）
- **公式**：`=MOD(数字, 除数)`
- **示例**：`=MOD(A2, 2)` 结果为 1 是奇数、0 是偶数

## 表格操作技巧（非公式，但每天用）

### 冻结窗格（表头不动）
- **操作**：选中"表头下面第一行"的第一个单元格 →「视图」→「冻结窗格」→「冻结首行」
- **场景**：表格几千行往下滚时，永远看得见表头

### 下拉列表（防止填错）
- **操作**：选中要设置的列 →「数据」→「数据验证」→「允许：序列」→ 来源填 `销售部,财务部,行政部`（逗号用英文）
- **注意**：来源也可以引用一个区域：`=$F$1:$F$10`

### 删除重复项
- **操作**：选中数据区域 →「数据」→「删除重复值」
- **注意**：会直接改原始数据，先复制一份再删

### 分列（把一列拆成多列）
- **操作**：选中该列 →「数据」→「分列」→ 选"分隔符号"或"固定宽度"
- **场景**：把"张三-销售部-北京"拆成三列

### 定位空值（对账经典技巧）
- **操作**：选中区域 → `Ctrl+G`（或 F5）→「定位条件」→「空值」→ 直接输入内容按 `Ctrl+Enter` 批量填充
- **场景**：把空白的负责人批量填成同一个名字

### F4 键：切换绝对/相对引用
- **作用**：编辑公式时选中引用部分按 F4，`A1` → `$A$1` → `A$1` → `$A1` 循环切换
- **场景**：公式要往下拉但某个区域不想跟着变时

### 条件格式标红预警
- **操作**：选中区域 →「开始」→「条件格式」→「突出显示单元格规则」→「大于」输入阈值 → 设红色
- **场景**：库存低于安全值标红、账龄超期标红

### 数据透视表（5 秒出汇总）
- **操作**：选中数据区域 →「插入」→「数据透视表」→ 把"行"拖字段、"值"拖数字字段（默认求和，右键值字段可改计数/平均）
- **场景**：按部门汇总金额、按月份统计数量，比写公式快十倍

### 保护工作表（防误改）
- **操作**：全选 → 右键「设置单元格格式」→「保护」→ 取消"锁定" → 再选中要保护的区域勾上"锁定" →「审阅」→「保护工作表」设密码
- **场景**：模板发下去，只让同事改黄色区域
