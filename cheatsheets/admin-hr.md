# 行政 / HR 岗位速查（考勤 · 合同 · 花名册 · 招聘）

> 面向行政专员、HRBP、招聘、薪酬岗的高频操作。每条给「作用 / 公式(或操作) / 示例 / 注意」。
> 通用函数（VLOOKUP / COUNTIFS / IF / MID / DATEDIF / EDATE 等）基础语法见《excel-formulas》篇，本篇讲人事场景怎么套。
> 分类：考勤统计 → 合同与工龄 → 身份证信息提取 → 花名册与筛选 → 排班表 → 招聘漏斗

## 考勤统计

### COUNTIFS 数迟到 / 缺勤 / 早退
- **作用**：一张打卡表，统计每个月某人迟到了几次、缺勤几天
- **公式**：`=COUNTIFS(姓名列, 张三, 状态列, "迟到")`
- **示例**：统计张三本月迟到次数：`=COUNTIFS(A:A, "张三", D:D, "迟到", B:B, ">=2026-09-01", B:B, "<=2026-09-30")`
- **注意**：日期条件要同时写"大于等于月初"和"小于等于月末"，别只写一个；姓名两边都没空格，先 TRIM

### 应出勤天数
- **公式**：一个月去掉周末和节假日的工作日数。思路：`=NETWORKDAYS(月初, 月末, 节假日区域)`
- **注意**：NETWORKDAYS 是"工作日"函数，节假日要自己列一个区域传进去；国庆、春节这种长假要手动维护在表里

### 加班时长计算
- **公式**：下班打卡时间减标准下班时间，`=MOD(打卡时间-18/24, 1)*24`（小时数）
- **注意**：Excel 里时间是天，乘 24 才是小时；跨过半夜要加 MOD 处理

### 打卡异常筛出来
- **操作**：打卡表加一列判断：`=IF(上班时间>TIME(9,0,0),"迟到",IF(下班时间<TIME(18,0,0),"早退",""))`
- **注意**：TIME(9,0,0) 就是上午 9 点；标准上下班时间写死在公式里不好改，建议放到一个固定单元格，公式里引用它

### 月度考勤汇总（透视表法）
- **操作**：选中一个月的打卡明细 → 数据透视表 → 行放"姓名"，值拖三次"状态"，都设成计数，分别筛"迟到""缺勤""请假"
- **注意**：比写一堆 COUNTIFS 快，加人删人只要刷新

## 合同与工龄

### DATEDIF 算工龄
- **作用**：入职日期到今天的整年数，算年假、司龄工资
- **公式**：`=DATEDIF(入职日, TODAY(), "Y")`
- **示例**：`=DATEDIF(B2, TODAY(), "Y")` 得到 3，就是满 3 年
- **注意**：DATEDIF 只算"满"的整年，不满 1 年返回 0；要精确到月就加一列 `=DATEDIF(B2,TODAY(),"YM")` 补零头

### 合同到期提醒（EDATE + TODAY）
- **作用**：合同签了 3 年，自动算出哪天到期，快到 30 天高亮出来
- **公式**：到期日 `=EDATE(签订日, 36)`；剩余天数 `=到期日-TODAY()`
- **示例**：`=EDATE(B2,36)-TODAY()` 还有多少天到期；再配条件格式"小于 30"标红
- **注意**：EDATE 出来的是日期，直接减 TODAY() 就是天数；WPS 直接可用，老 Excel 要加载分析工具库

### 试用期到期提醒
- **公式**：`=EDATE(入职日, 6)` 六个月试用期满；同理做条件格式，剩余 ≤7 天变黄
- **注意**：试用期和合同期要分开两列管，别混

### 年假自动计算
- **思路**：司龄 1–10 年 5 天，10–20 年 10 天，20 年以上 15 天，用 IF 嵌套：
  `=IF(工龄>=20,15,IF(工龄>=10,10,5))`
- **注意**：入职不满一年的按"当年剩余天数 / 365 × 年假天数"折算，公式要另写一列

## 身份证信息提取

### 从 18 位身份证取性别
- **公式**：`=IF(MOD(MID(身份证格,17,1),2)=1,"男","女")`
- **示例**：`=IF(MOD(MID(A2,17,1),2)=1,"男","女")` —— 第 17 位奇数是男，偶数是女
- **注意**：MID 取出来是文本，MOD 会自动转数字，不用额外 VALUE；15 位老身份证在最后一位取奇偶

### 从身份证取出生日期
- **公式**：`=--MID(A2,7,8)` 然后把单元格格式设成日期；或 `=TEXT(--MID(A2,7,8),"0000-00-00")` 显示成 1990-01-01
- **示例**：A2 是 110101199003071234，`=MID(A2,7,8)` 得到 19900307
- **注意**：前面两个减号 `--` 是把文本"19900307"转成 Excel 认的日期数字；直接拼出来的是文本，没法算年龄

### 用生日算年龄
- **公式**：`=DATEDIF(生日格, TODAY(), "Y")`
- **注意**：不要写 `=YEAR(TODAY())-YEAR(生日)`，那个在生日没到之前会多算一岁；要简单算粗略年龄才用后者

### 籍贯 / 省份提取
- **公式**：`=LEFT(A2,2)` 拿到身份证前两位地区码，再去对照表 VLOOKUP 出省名
- **注意**：11=北京、31=上海、44=广东这种对照表自己维护一张，别写死在公式里

## 花名册与筛选

### 自动筛选（最常用）
- **操作**：选中表头 →「数据」→「筛选」（快捷键 `Ctrl+Shift+L`），列头出现小箭头，点一下就能按部门、在职状态筛
- **注意**：筛选隐藏的行不会被打印；做报表前确认没有残留筛选

### 高级筛选（按多个复杂条件提取）
- **作用**：要把"部门=销售部 且 入职时间>2024 且 学历=本科"的人单独拎出来
- **操作**：先在空白区域写条件区（第一行列名和表头一致，第二行写条件，同行是"且"，不同行是"或"）→「数据」→「高级」→ 选"将筛选结果复制到其他位置"
- **注意**：条件区的列名必须和原表一模一样，多一个空格都认不出来

### 下拉列表限制部门 / 状态填写
- **操作**：选中列 →「数据」→「数据验证」→「序列」→ 来源填 `在职,试用期,离职,实习`
- **注意**：防止手滑把"在职"写成"在职 "，后续统计就漏了

### 重复身份证号检查
- **公式**：`=COUNTIF(A:A, A2)>1` 为 TRUE 就是有重复
- **操作**：加一列辅助列 `=IF(COUNTIF(A:A,A2)>1,"重复","")`，再筛出"重复"
- **注意**：入职两人录错同一份身份证是 HR 经典事故，录完必查

### 照片批量插入花名册
- **操作思路**：照片以工号命名（如 1001.jpg）放同一个文件夹 → 用 PHOTOS 类加载项或 WPS 的"图片批量导入"功能，按工号匹配插进对应行
- **注意**：手动一格格插会卡爆，别这么干

## 排班表

### 下拉列表选班次（早 / 中 / 夜 / 休）
- **操作**：选中整月排班区域 →「数据验证」→ 序列来源 `早班,中班,夜班,休`
- **注意**：配合条件格式，"休"那格自动变灰

### 条件格式自动标周末
- **操作**：选中排班表日期行 →「条件格式」→「新建规则」→ 用公式 `=WEEKDAY(A$1,2)>5` → 设浅灰底
- **注意**：`WEEKDAY(...,2)` 返回 1=周一 … 7=周日，>5 就是周六周日；公式里列锁死、行不锁，这样横拖竖拉都能判断对

### 每人每月上班天数统计
- **公式**：`=COUNTIF(B2:AF2, "休")` 数休息天数；`=30-COUNTIF(B2:AF2,"休")` 就是上班天数
- **注意**：横向一整行统计，区域别漏列

### 连续上班不超过 6 天检查
- **思路**：加一列辅助用 `COUNTIF` 不好判断连续，最稳妥是人工看一眼；或者写条件格式公式找连续非"休"的段
- **注意**：这种合规检查别完全靠公式，排班表打出来过一眼

## 招聘漏斗

### 各阶段人数统计
- **公式**：`=COUNTIFS(招聘表!状态列, "初筛通过")`
- **示例**：面试漏斗 = 简历投递 → 初筛 → 一面 → 二面 → Offer，每段一个 COUNTIFS
- **注意**：状态字段一定要用下拉列表规范填，别有人写"一面过了"有人写"一面通过"，统计就断了

### 各岗位招聘进度
- **操作**：数据透视表 → 行放"岗位"，列放"状态"，值放计数
- **注意**：一张图同时看到每个岗在哪个阶段卡了多少人，周报直接截图用

### 招聘转化率
- **公式**：`=Offer数 / 简历投递数`；环节转化率 `=下一阶段数 / 本阶段数`
- **注意**：除以 0 会报错，外面包 `=IFERROR(...,0)`

### 候选人重复投递排查
- **公式**：`=COUNTIF(手机号列, 手机号格)>1`
- **注意**：候选人用不同手机号投不同岗位，这种查不到，要靠姓名+邮箱补查

## 行政日常

### 员工通讯录两表合并（VLOOKUP 补字段）
- **作用**：HR 系统导出一份有姓名工号，行政手里一份有部门座位，合成一张完整通讯录
- **操作**：选 HR 表为底，用 VLOOKUP 按工号把部门、电话补过来；或反过来
- **注意**：两表都先 TRIM 工号，否则前导零或空格导致 VLOOKUP 失败

### 办公用品领用统计
- **公式**：`=COUNTIFS(领用人列, "张三", 物品列, "中性笔")`
- **场景**：季度看谁领了多少笔，判断是不是真的办公用品被私用
- **注意**：领用人字段用下拉列表规范，别有人写"张三"有人写"小张"

### 会议室预定冲突检查
- **思路**：预定表列"日期+会议室+开始时间+结束时间"，用 COUNTIFS 数同会议室同时间段出现几次，>1 就是冲突
- **注意**：跨天的长会议要拆成多行，或单独标注

### 值班表隔行填名（MOD 技巧）
- **公式**：`=IF(MOD(ROW(),2)=1,"张三","李四")` 奇偶行轮流
- **注意**：ROW() 取当前行号，从哪行开始排要对齐；节假日单独列手动改

### 离职人员一键归档
- **操作**：对"状态"列筛选"离职" → 整行复制到"离职员工"Sheet → 原表删除；别直接删，留档
- **注意**：社保、公积金、背调证明这些以后还要开，档案别清

### 入职登记表必填校验
- **操作**：选中要必填的列 →「数据验证」→ 选"自定义" → 公式 `=LEN(A2)>0`，出错警告设"停止"
- **注意**：下拉列表负责规范选项，数据验证负责非空，两个一起上

### 社保公积金基数核对
- **思路**：每年 7 月调基数，把去年月均工资列和今年基数列并排，差额列标红，超出 3% 的人工复核
- **注意**：封顶 / 保底基数当地社保每年公布一次，单独存一个表引用

### 节日 / 生日提醒
- **公式**：`=TEXT(B2,"mm-dd")` 提取月日，和 `TEXT(TODAY(),"mm-dd")` 比，相等就是今天生日
- **注意**：DATEDIF 在这里算年龄时要考虑 2 月 29 日出生的人，平年怎么处理单独和 HR 对口径

---
*本速查表为原创整理，基于 Microsoft Excel 与 WPS 通用函数语法。具体考勤、年假、合同期限口径以公司制度和当地劳动法规为准。*
