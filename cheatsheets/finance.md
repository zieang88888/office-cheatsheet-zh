# 财务 / 会计岗位速查（对账 · 税务 · 账龄 · 报表）

> 面向出纳、会计、财务分析岗位的高频操作。每条给「作用 / 公式(或操作) / 示例 / 注意」，照着抄就能用。
> 通用函数（VLOOKUP / SUMIFS / COUNTIFS / DATEDIF / ROUND 等）的基础语法见《excel-formulas》篇，本篇只讲财务场景怎么用。
> 分类：两表对账 → 金额精度与尾差 → 价税计算 → 账龄与往来 → 汇总与透视 → 审核与安全

## 两表对账

### VLOOKUP 法核对两张表的差异
- **作用**：把 A 表（如系统导出）的金额拉到 B 表（如银行流水）旁边，一眼看出哪一行对不上
- **公式**：`=VLOOKUP(关键字, 另一张表区域, 返回列数, 0)` 旁边再写一个 `=本表金额-查找过来的金额`
- **示例**：B 表有"凭证号"和"金额"，在 A 表旁边写 `=VLOOKUP(C2, 银行流水!$A$2:$B$1000, 2, 0)`，再下一列 `=D2-E2`，差额为 0 就是平了
- **注意**：查不到会出 #N/A，外面包一层 `IFERROR(...,"")` 把空行藏掉；差额列用条件格式把不等于 0 的标红

### 条件格式法并排标红差异
- **作用**：不想写公式时，直接让 Excel 自己把两边不一致的单元格标出来
- **操作**：选中两列要对比的区域 →「开始」→「条件格式」→「新建规则」→「使用公式确定要设置格式的单元格」→ 输入 `=A1<>B1` → 设红色填充
- **注意**：活动单元格选在区域左上角，公式里写相对引用（不要加 $）；日期和数字要确保两边都是同一类型，否则明明相等也会被判成不等

### 定位空值批量填充（对账经典动作）
- **作用**：合并单元格复制出来后，只有第一行有部门名，下面全是空，先填满才能透视
- **操作**：选中那一列 → `Ctrl+G` →「定位条件」→「空值」→ 输入 `=上一行那个单元格`（比如 `=D2`）→ 按 `Ctrl+Enter` 全部填好
- **注意**：填完之后整列复制 → 右键「选择性粘贴 → 数值」，不然删掉原表这列就全乱了

### 合计不平，快速定位错行
- **作用**：借方合计比贷方多了几分钱，不知道哪笔错了
- **操作**：先看差额是多少 → 用 `Ctrl+F` 搜这个数；再搜差额的一半（可能是某笔方向记反了）；还找不到就逐行加总，在差额附近用"定位条件 → 文本型数字"看看有没有数字被存成了文本
- **注意**：银行流水最常见的坑是金额带千分位逗号或前面有空格，看着像数字其实是文本，加不进去

### 显示公式 / 追踪引用单元格
- **作用**：审核别人做的表，想知道这个合计数是从哪些格子加出来的
- **操作**：`Ctrl+[`（左中括号）直接跳到所有引用的单元格；`Ctrl+]` 找是谁引用了当前格；`Ctrl+``（数字 1 旁边那个反引号）整表公式和数值来回切
- **注意**：跳到引用格之后按 `Esc` 取消选中再改，别不小心把公式删了

### 选择性粘贴为数值
- **作用**：算好的结果要粘到另一个表，不能带公式（源表一删就全报错）
- **操作**：复制原区域 → 到目标位置右键 →「选择性粘贴」→ 选「数值」（快捷键 `Ctrl+Shift+V` 后选值）
- **注意**：带格式一起粘就选「值和数字格式」，粘过去的金额不会变成普通数字串

## 金额精度与尾差

### ROUND 金额保留两位小数
- **作用**：金额、税额必须到分，不能一串小数点
- **公式**：`=ROUND(计算式, 2)`
- **示例**：`=ROUND(B2*0.13, 2)` 算销项税并保留两位
- **注意**：ROUND 是真的把数字变成两位；只设"显示两位"而不用 ROUND，后台还是一长串，加总时会出现"看着平加起来不平"

### 防尾差：先 ROUND 再求和
- **作用**：每行金额都四舍五入到分，再加总；反过来先加总再 ROUND，最后总数和明细对不上（差几分钱）
- **正确顺序**：明细列先用 `=ROUND(单价*数量, 2)` → 合计再 `SUM(明细列)`
- **反面教材**：`=ROUND(SUM(单价*数量), 2)` 这种写法每笔没舍入，合计出来的和你逐笔算出来的总是差几分
- **注意**：如果业务要求"每行不四舍五入、只在合计处取整"，那就要和对方对账口径说清楚，别两头各算各的

### TRUNC / INT 直接截断（不要四舍五入时用）
- **公式**：`=TRUNC(数字, 2)` 直接砍到两位，不四舍五入；`=INT(数字)` 向下取整
- **场景**：某些内部核算口径要求"只舍不入"，比如折扣分摊
- **注意**：和 ROUND 的差别是 1.239 用 ROUND 得 1.24，用 TRUNC 得 1.23，用错会被审计挑

### 分与元的单位换算
- **作用**：系统导出的金额常以"分"为单位，要转回"元"
- **公式**：`=金额/100`；从元转分就 `=金额*100`
- **注意**：乘除完记得再 ROUND 两位，避免二进制浮点误差冒出来一长串

### 人民币金额大写（写报销单 / 支票用）
- **思路（不硬编长公式，避免版本兼容出问题）**：
  1. Excel 没有自带"转大写金额"函数，网上流传的 TEXT 嵌套公式很长，且不同地区会计科目用字（角、分、整）要求不一，直接复制容易出错；
  2. 推荐做法：写好数字后，用「设置单元格格式 → 数字 → 特殊 → 中文大写数字」先把整数部分转出来，再手工补"圆、角、分、整"几个字；
  3. 正式对外的支票 / 合同，建议用财务软件自带的大写打印功能，或搜索"人民币金额大写公式"后先拿 0.5、100、1000.01、1000000.002 几个边界值验证一遍再大面积用。
- **注意**：数字 0 的大写"零"在连续位置要不要写、末位要不要加"整"，不同公司要求不同，以本单位报销制度为准

## 价税计算

### 价税分离：不含税金额 = 含税 ÷ (1 + 税率)
- **作用**：拿到一张含税发票，要拆出不含税收入和税额
- **公式**：不含税金额 `=含税金额/(1+税率)`；税额 `=不含税金额*税率`
- **示例**：含税 113 元，税率 13%：`=113/1.13` = 100 元，税额 13 元
- **注意**：除出来的数记得 ROUND(...,2)，否则系统里两位小数和你手算的会差一分

### 含税价倒算（已知不含税要报含税）
- **公式**：`=不含税金额*(1+税率)`
- **示例**：不含税报价 100，开 13% 专票：`=100*1.13` = 113
- **注意**：报给客户的含税价通常保留两位，`=ROUND(...,2)` 一下

### 多档税率混合求和
- **作用**：一张表里既有 13% 又有 6% 的项目，要分别汇总销项税
- **公式**：`=SUMPRODUCT((税率列=0.13)*含税列/1.13*0.13)`；更清晰的做法是加一列"不含税"和"税额"，再用 SUMIFS 按税率汇总
- **注意**：直接在 SUMPRODUCT 里做除法要小心除零，税率列为空会出 #DIV/0!

### 按客户汇总应收
- **公式**：`=SUMIFS(金额列, 客户列, "XX公司", 账期列, "2026-09")`
- **场景**：月底出每个客户的欠款明细
- **注意**：客户名一定要统一（"北京公司"和"北京公司 "多一个空格就对不上），先 TRIM 一遍

## 账龄与往来

### DATEDIF 算账龄
- **作用**：发票日到今天过了多少天 / 多少个月，判断超期
- **公式**：`=DATEDIF(开票日, TODAY(), "D")` 天数；`=DATEDIF(开票日, TODAY(), "M")` 月数
- **示例**：`=DATEDIF(A2, TODAY(), "D")` 算这笔应收挂了多少天
- **注意**：开始日期必须早于结束日期，否则报错；今天是周末 / 节假日不影响，DATEDIF 只认日历天

### 条件格式给账龄分级标色
- **作用**：0–30 天绿色、31–90 天黄色、90 天以上红色，一眼看出哪些该催了
- **操作**：选中账龄列 →「条件格式」→「突出显示单元格规则」→「大于」90 → 红；「介于」31 到 90 → 黄；剩下的设绿
- **注意**：规则顺序是"从上到下依次判断"，最严格的（>90）放最上面，否则被前面的规则吃掉

### EDATE / EOMONTH 算账期和月末结账日
- **作用**：合同写"月结 60 天"，算这笔款哪天到期
- **公式**：`=EDATE(开票日, 2)` 两个月后的同一天；`=EOMONTH(开票日, 1)` 下一个月的最后一天（即"次月月底"）
- **示例**：发票 9 月 15 日开，月结 60 天 ≈ `=EOMONTH(开票日, 2)` 即 11 月 30 日
- **注意**：EDATE 在老版本 Excel 要加载"分析工具库"，WPS 直接能用

### 应收应付按客户 / 供应商汇总
- **公式**：`=SUMIFS(金额列, 客户列, F2)` 配客户列表逐行出合计；或者直接拖数据透视表
- **注意**：往来单位经常加了备注（"XX公司-总部"），透视前先把备注列拆出来，不然会被当成两家客户

## 汇总与透视

### 数据透视按月份汇总费用
- **作用**：一整年的费用明细，几秒出每月合计
- **操作**：选中明细 →「插入」→「数据透视表」→ 行放"月份"（没月份列就先加一列 `=TEXT(A2,"yyyy-mm")`），值放"金额"求和
- **注意**：日期列要真的是日期格式，不能是文本，否则透视表里没法按"月"自动分组；右键日期字段 →「组合」→ 选"月、年"

### 透视表刷新
- **作用**：源表加了几行数据，透视表不会自动变
- **操作**：点透视表任意格 → 右键「刷新」；想每次打开自动刷就「数据」→「属性」→ 勾"打开文件时刷新"
- **注意**：源表范围如果新增了行没被透视捕获，要点「分析」选项卡 →「更改数据源」重新选一遍范围

### 银行流水逐笔匹配
- **作用**：把企业银行日记账和银行对账单一笔笔勾对
- **操作思路**：两表都用"日期+金额"做拼接键（`=TEXT(A2,"yyyy-mm-dd")&"|"&B2`），再 VLOOKUP 到对方表，找不到的就是未达账项
- **注意**：同一天多笔同金额的业务（比如发工资）会撞键，要再加一个"摘要"字段一起拼

## 审核与安全

### 保护工作表，只开放录入格
- **作用**：费用报销模板发下去，同事只能填黄色格子，公式区动不了
- **操作**：全选整张表 → 右键「设置单元格格式」→「保护」→ 取消"锁定"勾选 → 再框选允许填的格子，勾上"锁定"取消掉（即只锁定公式区）→「审阅」→「保护工作表」设密码
- **注意**：默认所有格子都是"锁定"状态，但只有在工作表被保护后锁定才生效；别把密码忘了

### 隐藏错误值
- **作用**：空行的 VLOOKUP 全是 #N/A，打印出来难看
- **公式**：`=IFERROR(原公式, "")`
- **注意**：空字符串 "" 看起来是空，但筛选时它和真空格不一样，筛选"空白"选不中它

### 打印时每页重复表头
- **操作**：「页面布局」→「打印标题」→ 顶端标题行选 `$1:$1`（表头那行）
- **场景**：凭证汇总表打几十页，每页都要带科目名

### 冻结窗格
- **操作**：点表头下第一行 →「视图」→「冻结窗格」→「冻结拆分窗格」
- **场景**：几百行的科目余额表，往下滚还能看到列名

### 跨表引用语法
- **作用**：在 A 表取 B 表某格的值，不用来回切
- **公式**：`=表名!单元格`，表名带空格或中文时要加单引号 `='2026-09 银行流水'!B2`
- **注意**：源表删了或改名，引用会报 #REF!；源表整列删了同样会报错

### 多 Sheet 合并汇总（合并计算）
- **作用**：12 个月的费用表分别在 12 个 Sheet，要一张汇总表
- **操作**：在汇总表选起点格 →「数据」→「合并计算」→ 逐个把每个 Sheet 的数据区域加进去 → 勾"首行 / 最左列"
- **注意**：各 Sheet 的表头和行项目名字必须一模一样，否则会被当成新项目列出来；用之前先统一命名

### 借贷方向筛选
- **作用**：只想看贷方发生额有哪些
- **操作**：对"方向"列加自动筛选，只勾"贷"；或加辅助列 `=IF(贷方>0,"贷",IF(借方>0,"借",""))`
- **注意**：借贷在不同两列时，别用筛选一列，要在辅助列里判断

### 发票 / 凭证号查重
- **公式**：`=IF(COUNTIF(A:A,A2)>1,"重复","")`
- **场景**：月末录凭证前查一遍号，防止一张票录两次
- **注意**：号前有空格也会被当成不同，先 TRIM

### 银行流水导入后日期格式统一
- **操作**：银行回单导出的日期常是"2026/9/1"文本，选中该列 →「数据」→「分列」→ 直接点完成，Excel 会自动识别成真日期
- **注意**：分列是把文本日期批量转日期最稳的办法，比一个个 VALUE 快

### 费用按部门 SUMIF 快速出合计
- **公式**：`=SUMIF(部门列, "销售部", 金额列)`
- **场景**：部门费用看板，每个部门一行一个公式
- **注意**：和 SUMIFS 区别就是只一个条件；多条件必须用 SUMIFS

### 表格打印前把网格线去掉
- **操作**：「页面布局」→ 把"查看网格线"的打印勾去掉
- **注意**：财务凭证不要带 Excel 默认网格线打出来，太糙；需要的边框自己加细横线
